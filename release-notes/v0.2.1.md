## rbx-cli 0.2.1

Adds a native **Windows on Arm (ARM64)** build. No protocol or behavior changes: the protocol version stays `2`, and the request and response formats are the same as in [0.2.0](https://github.com/tainakanchu/rbx-cli/releases/tag/v0.2.0).

> Not affiliated with AlphaTheta / Pioneer DJ. rekordbox and CDJ are their trademarks.
> **Not yet verified on physical players.** Check a stick on a player before relying on it at a gig.

### Changes

- New release asset `rbx-cli-0.2.1-aarch64-pc-windows-msvc.zip`. It is cross-compiled on x64 and smoke-tested (`version --json`, PE machine check) on a native Windows Arm runner before the release is created. `version --json` reports `"target": "windows-aarch64"`.
- The release workflow can be run by hand (`workflow_dispatch`) as a dry run. It builds and tests every target and creates no release.
